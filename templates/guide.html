How to use Ledger

Ledger is a calm practice log — check in with what’s here, plan the day, and record skills work. Nothing is required. Use only the pieces that help.

On this page

  • Today
  • Check-in
  • Add tools
  • Mantras
  • Log

1. Set yourself up

Start in Settings. These lists follow you across Today, Check-In, and diary-style forms.

  • Tracked emotions

    Short list of feelings you want easy access to (e.g. Content, Anxious). On forms they appear as chips — tap one only when you want to rate it (1–5). Untouched emotions are not saved, so you won’t get a wall of “3”s.

  • Target behaviors

    Behaviors you’re watching urges around. Used on Today and when you note an urge on Check-In. You can also add one on the form itself; it stays in your list.

  • Feelings wheel

    Optional reference image on Check-In to find a more precise word. Turn it off in Display if you don’t need it.

  • Saved customs

    When you type your own emotion or skill via “Other,” Ledger remembers it for next time under Saved. Remove a saved item from any picker and it’s gone everywhere for you.

2. Today — the daily anchor

Today is one entry for the day. Open it from the home tab, or Start today if you haven’t filled it yet.

  • Emotions — rate tracked chips only if they apply; add other emotions if you want.
  • Target behavior urges — optional 1–5 ratings.
  • Daily affirmation — a short line to carry.
  • How I show up — stance for the day (required).
  • A tiny bit better — small improvement + reward.
  • Committed actions — add/edit/remove concrete actions (done tracking lives in Long Track).
  • Hour-by-hour agenda — optional; only fill hours that matter.

Today’s focus on the home card comes from mantras you’ve set as focus — pick from existing mantras, don’t create new ones there.

3. Check-In — quick notice

Use Check-In when something is present and you want to set it down without filling a full day plan.

  • Tap tracked emotions to rate, or skip them.
  • Add other emotions by name (intensity optional).
  • Write thoughts — what’s the mind saying.
  • Urges stay tucked under “Any urge present?” so they don’t dominate.

4. Add — skills & worksheets

The Add tab lists practice tools. Ratings use a shared 1–5 slider. Older entries kept on a 1–10 scale stay that way when you edit them.

  • Skill used — which DBT module and skill you practiced.
  • Thought record — situation, thought, emotions before/after, validity, alternative thought.
  • Opposite action — plan, then come back later to re-rate after you act.
  • Behavioral activation / Exposure — two-step: save a plan, complete outcome from Home → In progress.
  • ABC / Chain analysis — structured worksheets when you need them.
  • Journal — write and/or record audio from the microphone. Text or a recording is enough.

5. Mantras

Open Mantras from Add. Create and edit your library there. From Home you only set today’s focus from mantras you already have. Each add / focus / edit / delete is logged.

6. Log

Log is your history. Open any entry to review, edit, or finish an in-progress outcome. Some entries can be marked for review (e.g. for therapy export).

Tips

  • Less is fine. A check-in with one thought counts.
  • Keep tracked emotions short — five or fewer is usually enough.
  • Invite others from Settings if you share an instance (invite-only registration).
  • If you use Long Track, completed moments can sync there automatically when the bridge is configured.
